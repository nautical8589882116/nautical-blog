Stop retyping the printed menu

An AI menu builder is not a slogan here. In NHY you build categories with a colour and an image, then items with a price, calories, and flags for veg, spicy, and featured. Each item can be available for Breakfast, Lunch, or Dinner, so the morning card does not keep selling a dinner plate at 9 a.m.

If the menu already exists on paper, Import from photo reads a picture of that printed menu and builds the categories and items for you. A retail catalogue does not need a photo of a card: Shopify CSV import brings the shop list in. The same screen also carries catalogue profiles — restaurant, café, bar and pub, retail shop, grocery, and others — so the fields match the counter, not a generic form.

A restaurant owner uses meal windows so lunch specials drop off before dinner. A café owner flags the featured pastry. A bar manager marks spicy wings. A shop owner imports the catalogue and uses the same item card for price and availability.

The table should not have to wave

Contactless ordering means a QR code on the table. The guest opens the phone camera, scans, and lands on a web menu. There is no app to download. They pick a portion — Quarter, Half, or Full — apply a coupon, and see a live summary: subtotal, service charge, tax, and discount.

That QR code ordering system is the same at a café counter, a bar high-top, and a shop rail. Restaurant POS software usually stops at the till. NHY starts at the table.

Pending, preparing, ready, done

The order pipeline is four states: Pending, Preparing, Ready, Completed. Filter by date, table, payment method, and status. Send the receipt from the order.

On the dashboard, today’s revenue, orders, and average order value sit above recent tickets. Billing, team accounts, and store settings live in the same deck.

Find the empty shelf before the guest does

NHY keeps food stock and retail stock, raises low-stock alerts, and supports purchase orders and transfers between locations.

For a restaurant: a prep item before dinner. For a café: milk and the featured pastry. For a bar: the bottle for the next round. For a shop: the size that transfers from the other location.
